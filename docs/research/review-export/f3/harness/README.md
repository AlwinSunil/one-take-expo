# Decoded audio fixture comparison

`MediaAudioProbe.java` is an isolated Android research helper, compiled into the temporary `dev.onetake.npu` harness. It does not modify One Take or use a host decoder. The entry point is `MediaAudioProbe.inspect(filesDir, logConsumer)`; the activity runs it on its worker thread with the `media_audio` intent mode. Input filenames are `media-source.mp4` (the 12-second synthetic source) and `media-export.mp4` (its completed 8-second export), copied to that harness's private files directory. Keep the source and output job ID in the device evidence.

The helper uses Android MediaExtractor/MediaCodec to decode both audio tracks. It places decoded samples on their container presentation timeline, drops negative priming samples, requires matching sample rates, averages channels and supports PCM16/float. A 20-second input limit and 60-second decoder timeout bound the experiment. It does not infer results from compressed packet counts.

For source intervals `[0,4)` and `[8,12)`, it locates voiced boundaries using 10 ms RMS windows (threshold: greater of 0.001 full scale and 6% of the phrase's peak RMS). It reports onset/offset differences against output intervals `[0,4)` and `[4,8)`. It compares 350 ms near the beginning and end of each voiced phrase using mean-centered normalized waveform correlation, searching +/-150 ms. Fixed pass criteria are correlation >=0.8 in all four windows, absolute lag/onset/offset error below 100 ms, plus a quiet join between output 3.85 and 4.35 seconds. The join threshold is greater of 0.005 full scale and three times the adjacent source silence RMS.

These criteria are specified before the phone execution. A failure remains a failure; do not loosen thresholds after observing the result. Voice boundaries are energy estimates, not recognizer word alignments. A passing result establishes retained padded synthetic phrase boundaries and bounded decoded audio timing for this fixture, not perceptual human lip sync, arbitrary speech edit safety, transcription quality or a frame-accurate production editor.
